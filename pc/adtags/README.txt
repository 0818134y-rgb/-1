忍者AdMax など、AdSense 以外の広告サービスの「広告タグ」を置く場所。
管理画面でコピーした HTML を、そのままファイルに貼り付けて保存する（UTF-8）。
  banner_sp.html … スマホ用バナー（320×50 など）。ロビー・結果画面の下に出る
  banner_pc.html … PC 用バナー（728×90 など）。無ければスマホ用を使う
  break.html     … ゲームの合間の休憩画面に出す広告（300×250 など）。無ければバナーを使う
  page.html      … 遊び方などの読みものページの下に出す広告。無ければバナーを使う
置いたら python3 pc/build.py で作り直して公開する。
