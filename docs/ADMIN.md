# 管理者アプリ（わちゃパ管理）

荒らし対策のための、運営者だけが持つ Android アプリです。ふつうの「わちゃパ」と並べて入れられます（別のアプリ扱い）。広告は出ません。

## できること
- **部屋に入る**：オンラインの部屋コード（6けた）を入れると、管理者としてその部屋に入れます。ゲーム中・満員でも入れます。入ると部屋の全員に「🛡 管理者が部屋の様子を確認しています」と表示されます。
- **様子を見る**：参加者の一覧（名前・端末番号）と、選んだ参加者の画面をそのまま見られます（見るだけで、操作はできません）。
- **退出させる**：だれでも退出させられます（ホストを退出させると部屋が閉じます）。
- **BAN**：「この部屋だけ」か「全部屋共通」を選べます。全部屋共通の BAN をされた端末は、どの部屋にも入れず、オンラインの部屋も作れません。
- **部屋の操作**：次へ進める（話し合い・投票・回答などを締め切る）、ゲームを止めてロビーへ、部屋を閉じる。
- **お知らせ**：部屋の全員にメッセージを出せます。
- **BAN リストの管理**：全部屋共通の BAN の一覧・解除・端末番号での追加。

## しくみ
- 管理者アプリには秘密鍵が入っています。部屋のホストの端末は、アプリに入っている公開鍵で管理者の署名を確かめてから従います（サーバーは使いません）。
- 全部屋共通の BAN リストは `https://wachapa.com/bans.json` です。端末番号は元に戻せない形（SHA-256）で入ります。管理者アプリが GitHub 経由で書きかえ、1〜5分で全部屋に反映されます。
- 端末番号はインストールごとのランダムな番号です。アプリの削除やブラウザのデータ削除で変わるため、BAN を完全に防ぐことはできません。

## 最初の設定（全部屋共通の BAN を使うとき）
1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
2. Repository access で「Only select repositories」→ サイトのリポジトリ（`-`）だけを選ぶ
3. Permissions → Repository permissions → Contents を「Read and write」
4. 作ったトークン（`github_pat_…`）を、管理者アプリの「全部屋共通の BAN リスト」画面に貼って保存

## 注意
- 管理者アプリ（APK）と `admin.properties`（秘密鍵）は人に渡さないでください。持っている人はだれでも管理者になれます。
- もし漏れたら、新しい鍵を作って `shared/src/commonMain/kotlin/com/zen/partygame/game/Admin.kt` の公開鍵を変え、全部のアプリを更新します。
- 近くで（Bluetooth・Wi-Fi）の部屋には入れません（オンラインの部屋だけ）。
- 作り方：`admin.properties` をプロジェクトの一番上に置き、`gradle assembleRelease -Padmin`
